# 今天吃什么 · 校园午餐决策器

第三届大学生人工智能通识应用大赛 · 参赛作品

## 在线体验

https://yibei2000.github.io/jintian-chi-shenme/

## 它解决什么

食堂门口站五分钟不知道吃什么。说清预算和忌口，10 秒给出三个可执行的选择；
用满五次之后，它会开始记得你的口味。

## 功能

- **预算 + 忌口筛选**：滑块选预算，多选忌口，互斥的「都不忌口」
- **排队时长**：食堂很挤时自动跳过等待超过 10 分钟的窗口，并说明跳过了几家
- **营养估算**：每份标热量与蛋白质，数值来自数据表，非凭空生成
- **换一个**：单张替换，另外两张不动，换过的不再重复出现
- **就吃这家**：记录真实选择，作为偏好信号
- **第 5 次起的「猜你喜欢」**：按历史预算、忌口、赶时间比例和上次的选择打分，用一句人话把推理写出来

## 本地运行

双击 `index.html` 即可，无需服务器、无任何依赖。

## 换成自己学校的食堂

编辑 `index.html` 里的 `DISHES` 数组，按同样字段填入窗口名、菜品、价格区间、忌口、等待时间、热量与蛋白质。

## 说明

- 偏好数据只存在浏览器 `localStorage`，不上传服务器
- 营养数值为估算值，仅供选餐参考
- 窗口数据为示例，正式使用前请替换为本校真实数据
